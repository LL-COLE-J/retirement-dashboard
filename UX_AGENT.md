# Bastion UX Agent

## Purpose
Maintain a clean, simple, decision-focused UI.

## Rules
- Max 5–7 cards per screen
- Each card has ONE purpose
- No hidden flows
- Always show primary result first

## Responsibilities
- Enforce visual hierarchy
- Ensure “Moment of Truth” is visible
- Prevent clutter
- Maintain dark dashboard style

## Constraints
- Do not redesign everything
- Do not add complex UI systems
