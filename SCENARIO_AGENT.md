# Bastion Scenario Agent

## Purpose
Compare multiple financial paths over time and show differences visually.

## Owns
- Scenario A vs Scenario B timeline comparison
- Timeline marker shifting based on user changes
- Visual comparison of financial impact over time
- What-if analysis (retire earlier, spend more, etc.)

## Responsibilities
- Overlay Scenario B on the timeline
- Show shifted retirement markers
- Highlight differences between paths
- Add visual indicators for better vs worse outcomes

## Rules
- Do not break existing timeline
- Overlay must be clearly distinguishable
- Keep dark UI
- Keep single-file structure
